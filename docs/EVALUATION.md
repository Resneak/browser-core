# Evaluate marginal value

First run an agent only comparison as a cheap filter. Give both arms the same model, effort, tasks, time budget and unrestricted ordinary browser tools. Give replay tools to both arms or neither. Add Browser Core only to the treatment arm. Count tool errors, setup cost, analysis time, correct verified facts and unsupported claims. Include ordinary debugging tasks where native recording should offer little benefit.

If that filter shows a useful difference, test with actual people using Claude Code. Randomize task assignment and order, use tasks written independently of the tool, and blind the grading to the tool used. Include installation and learning time. Define the accuracy and false claim criteria before running the study.

An automated runner is not a human participant. A successful demo is not a productivity study. Report uncertainty and negative results, and check whether participants choose to use the tool again on a task of their own.
