How to read this

A frame is a page or iframe. A worker runs JavaScript outside that page. A borrowed API can have a different owner from its JavaScript caller. Unresolved generated-binding script hints are not counted as execution script identities.

JS frame means the nearest visible JavaScript frame reported by the pinned V8 API. V8 filters by origin and skips non-JavaScript frames. Eval and regexp can report their root script rather than their immediate script. Limited context preserves a token while disposed context data is unavailable; not-recorded means the native recording has no such annotation.

A causal parent links an event to an earlier recorded event. Stack context alone never creates a causal edge. API names and counts do not reveal returned values. First/last event numbers locate a group's endpoints in the normalized JSONL; intervening rows can belong to other groups.

Passing validation and recording zero drop markers describe this artifact. They do not establish complete capture or instrumentation of every possible browser API.
